## 25.5 Standardized Reporting Schema

Every finding MUST be reported using this exact format:
- **Finding:** Short description.
- **Current Status:** Present technical condition.
- **Severity:** Critical / High / Medium / Low.
- **Business Impact:** Traffic / Ranking / Revenue / UX / Trust.
- **Root Cause:** Technical underlying reason.
- **Recommendation:** Detailed technical solution.
- **Implementation Steps:** Step-by-step resolution.
- **Priority:** P0 / P1 / P2 / P3.
- **Estimated Effort:** Small / Medium / Large.
- **Expected Result:** CTR / Indexation / Traffic gain.
- **Validation:** Method to verify resolution.
