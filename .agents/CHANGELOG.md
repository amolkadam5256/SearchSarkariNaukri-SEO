# CHANGELOG

All notable documentation changes, architectural updates, and SEO blueprint revisions for **SearchSarkariNaukri.com** are documented in this file.

## [2.0.0] — 2026-07-23

### Added
- Created modular documentation structure under `docs/` containing 25 dedicated markdown files (`01-business-foundation.md` through `24-kpis.md`, `README.md`, `SEO_AUDIT_AGENT.md`, and `CHANGELOG.md`).
- Added complete 12-sitemap specification (`sitemap.xml`, `sitemap-static.xml`, `sitemap-jobs.xml`, `sitemap-news.xml`, `sitemap-results.xml`, `sitemap-admit-cards.xml`, `sitemap-locations.xml`, `sitemap-districts.xml`, `sitemap-qualifications.xml`, `sitemap-departments.xml`, `sitemap-cross-filter.xml`, `sitemap-blogs.xml`).
- Added Generative Engine Optimization (GEO) protocol and root `/llms.txt` specification for AI Search engines (Google AI Overviews, Bing Copilot, ChatGPT).
- Added structured JSON-LD templates for `JobPosting`, `BreadcrumbList`, `FAQPage`, and `Organization`.
- Added programmatic SEO quality controls preventing thin content penalties on zero-job route combinations.
- Added E-E-A-T trust infrastructure policies (`/editorial-policy`, `/fact-check-policy`, `/corrections-policy`, `/disclaimer`).
- Added GA4 dataLayer event schema (`apply_click`, `alert_signup`, `download_click`).
- Added 90-day execution roadmap, master KPI targets, and risk register.

### Changed
- Standardized document naming format to numeric prefixes `01-name.md` through `24-kpis.md`.
- Expanded regional language strategy to include secondary language support (Marathi / Hindi).
