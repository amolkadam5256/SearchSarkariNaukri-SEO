# UI/UX, Accessibility and Responsive Requirements

Use existing design tokens and the installed icon set. Keep the current global header, navigation and footer. Prefer useful visual elements over decoration.

7. Creative UI/UX and responsive design requirements









Recruitment status card

Use a clear status label, latest verified date, active vacancy count only when supported by data, and a prominent official-notification link. Avoid large empty areas when no jobs match.











Quick navigation

Add anchor links for Notifications, Eligibility, Selection Process, Documents, Preparation, Related Jobs and FAQs. On mobile, use a compact collapsible navigation.











FAQ accordion

Use accessible buttons with clear expanded/collapsed states. Make questions readable, support keyboard navigation, and avoid hiding essential recruitment status or warnings inside the accordion.



Design acceptance checklist:
- [ ] Use the existing brand palette and typography.
- [ ] Use consistent line icons from the existing icon library.
- [ ] Use one primary accent color and restrained status colors.
- [ ] Keep cards aligned with consistent spacing and heading sizes.
- [ ] Ensure tables, source URLs, and long text wrap correctly on mobile.
- [ ] Provide clear hover, focus, active, loading, empty, and error states.
- [ ] Avoid unnecessary animations, decorative stock imagery, and excessive card nesting.
- [ ] Ensure the page remains useful without JavaScript-dependent content being unavailable to crawlers.
- [ ] Test at mobile widths, tablet widths, and desktop sizes.
- [ ] Preserve existing global navigation and footer.
