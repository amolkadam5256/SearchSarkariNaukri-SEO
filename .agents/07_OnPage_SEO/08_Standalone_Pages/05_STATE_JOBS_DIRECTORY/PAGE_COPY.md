## Intro

Central commissions like UPSC and SSC recruit for all India, but **posting**, **language**, and **domicile** rules often tie you to a state. State public service commissions — for example MPSC in Maharashtra, UPPSC in Uttar Pradesh, or RPSC in Rajasthan — publish separate calendars. This directory sends you to the right state hub on SearchSarkariNaukri. Each hub lists active jobs we track for that region plus links to popular exams.

If a state page shows few jobs today, still open the official state PSC site from our portal list — notifications may be mid-update. We do not hide states with low counts; we show what we have verified.

## H2 — Central jobs vs state jobs

**Central jobs** (UPSC, SSC, RRB, IBPS, major PSUs) may place you in any state. Read the “job location” column in the notification.

**State jobs** use state PSC or department portals — MPSC Rajyaseva, state police, Talathi, health, education, ZP. Start from the state link above, then filter by qualification on `/jobs`.

## FAQ

### How do I find home-state domicile jobs?

Open your state hub and read each notification’s domicile rule. Some posts are open to all India; others require state residency or language.

### Are these official state government websites?

We link to official sources from vacancy pages. This directory is part of SearchSarkariNaukri, an independent portal.

### Why does my state show zero active jobs?

The page still lists the state; counts reflect our current database, not whether the PSC has future exams planned.
