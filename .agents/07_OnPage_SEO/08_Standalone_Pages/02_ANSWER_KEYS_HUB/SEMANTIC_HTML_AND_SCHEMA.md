# Semantic HTML and schema — Answer Keys

- `<main>` → `<article>` → sections per commission (H2) with `<h3>` for exam names in table.  
- Use `<table>` with `<caption>`: “Government exam answer key status 2026”.  
- `<time datetime="…">` for exam dates where known.

**Schema:** BreadcrumbList, WebPage, FAQPage (FAQ section only).  
Optional `ItemList` for table rows linking to official URLs — only if URLs are live 200.
