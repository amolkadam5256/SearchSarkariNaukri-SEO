## Keyword Cannibalisation Rules

### Page Ownership Strategy
- **/jobs** = Government Jobs
- **/government-jobs/12th-pass** = 12th Pass Government Jobs
- **/government-jobs/maharashtra** = Maharashtra Government Jobs
- **/government-jobs/railway** = Railway Government Jobs
- **/exams/mpsc-rajyaseva** = MPSC Jobs

**Rule:** Do not make multiple pages equally target the same primary phrase.

## Keyword Placement Rules

### Primary Keyword Placement
- **Title:** Government Jobs 2026
- **H1:** Government Jobs 2026
- **First 100 words:** Use Government Jobs, Sarkari Naukri
- **One major H2:** Government Jobs by [Category]

- **Relevant H2/H3:** Government Jobs Closing Soon, Latest Government Jobs
- **Internal-link anchors:** Maharashtra Government Jobs, 12th Pass Government Jobs

### Long-Tail Keywords

## Implementation Steps

### Step 1: Keyword Research Validation
1. Validate search volume in Keyword Planner
2. Check competition levels in Ahrefs/Semrush
3. Analyze current ranking performance
4. Identify low-competition opportunities

### Step 2: Keyword Mapping
1. Map primary keywords to main pages
2. Map secondary keywords to sections
3. Map long-tail keywords to landing pages
4. Create keyword cannibalisation prevention rules

### Step 3: Content Optimization
1. Optimize title tags and meta descriptions
2. Update H1 and heading structure
3. Optimize body content naturally
4. Add FAQ sections for long-tail keywords

### Step 4: Landing Page Creation
1. Create qualification landing pages
2. Create location landing pages
3. Create department landing pages
4. Optimize each for specific keyword clusters

### Step 5: Monitoring and Iteration
1. Monitor Search Console performance
2. Track keyword rankings
3. Analyze user intent matching
4. Iterate based on performance data
