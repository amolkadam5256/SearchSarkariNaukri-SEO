## Page Creation Guidelines

### When to Create Dedicated Pages

**Create Page When:**
- [ ] Keyword has search volume (>50 monthly searches)
- [ ] Actual inventory exists (>5 jobs)
- [ ] Unique content can be created
- [ ] Clear user intent exists
- [ ] Internal link support available

**Do Not Create Page When:**
- [ ] Zero search volume
- [ ] No actual inventory
- [ ] Duplicate intent with existing page
- [ ] Overly specific with no demand
- [ ] Cannot create unique content

---

## Content Strategy

### Landing Page Structure

**Standard Structure:**
1. H1 with primary keyword
2. Introduction with secondary keywords
3. Current job listings (if applicable)
4. Eligibility information
5. Application process
6. Important dates
7. FAQ section
8. Internal links to related pages

**Content Length:** 500-1500 words depending on inventory and opportunity.

## Common Pitfalls

### Pitfall 1: Over-Targeting
**Problem:** Creating too many low-volume pages  
**Solution:** Focus on keywords with actual demand and inventory

### Pitfall 2: Thin Content
**Problem:** Creating pages with minimal content  
**Solution:** Ensure unique, comprehensive content for each page

### Pitfall 3: Cannibalisation
**Problem:** Multiple pages targeting same keyword  
**Solution:** Follow strict keyword ownership matrix

### Pitfall 4: No Inventory
**Problem:** Creating pages for queries with no actual jobs  
**Solution:** Only create pages when inventory exists

### Pitfall 5: Poor Maintenance
**Problem:** Creating pages and not updating them  
**Solution:** Regularly update content, remove outdated pages
