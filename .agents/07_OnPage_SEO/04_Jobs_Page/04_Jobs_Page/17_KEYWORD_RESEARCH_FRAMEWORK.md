## Important Disclaimer

**"Easy rank" is not a permanent property of a keyword.** Difficulty changes as competitors publish content and Google changes results.

**Use this framework to discover lower-competition opportunities rather than assuming a keyword is easy.**

## Tier A — Head Terms

### Examples
- jobs
- government jobs
- govt jobs
- sarkari naukri
- government recruitment
- railway jobs
- police jobs
- bank jobs

### Strategy
**Use as entity/topic terms, not as the only growth strategy.**

**Implementation:**
- Use in titles and headings
- Include in intro content
- Build topical authority
- Don't expect quick rankings

## Keyword Intent Labels

### Classify Every Keyword As

**Informational:**
- what are government jobs
- how to apply for government jobs
- government job eligibility

**Navigational:**
- searchsarkarinaukri
- MPSC official website
- SSC recruitment portal

**Commercial Investigation:**
- best government jobs
- highest paying government jobs
- government job vs private job

**Transactional/Application Intent:**
- apply online for railway recruitment
- MPSC application form
- SSC registration

**Local:**
- government jobs in Pune
- Mumbai police recruitment
- Maharashtra government jobs

**Freshness/Deadline:**
- government jobs closing today
- latest recruitment this week
- government jobs last date

**Question/AEO:**
- how to find government jobs
- which government jobs for 12th pass
- government job age limit

## Search Console Loop

### Monthly Optimization Process

**Every month:**
1. Export queries for /jobs
2. Group queries by intent
3. Identify queries with impressions but low clicks
4. Improve title/meta/snippet alignment
5. Identify queries that belong to another dedicated page
6. Add internal links
7. Improve content only where it answers a real query

---

## Low-Competition Opportunity Formula

### Best Candidates Often Combine
**topic + qualification + location + freshness**

**Examples:**
- 12th pass + Maharashtra + government jobs
- diploma + Pune + government jobs
- ITI + Maharashtra + recruitment
- government jobs + Solapur + this month
- government jobs + closing soon

**Validation:** Validate actual search demand before creating pages.

---

## Do Not Chase Every Keyword

### A Keyword Is Worth a Page When

**Criteria:**
- [ ] Intent is distinct
- [ ] There is real inventory
- [ ] The query can be answered substantially
- [ ] The page can be internally linked
- [ ] The page can remain useful over time

**Otherwise:** Keep it as a filter or FAQ phrase.

## Implementation Steps

### Step 1: Keyword Research
1. Use Google Keyword Planner for volume data
2. Use Ahrefs/Semrush for competition analysis
3. Use Search Console for performance data
4. Identify low-competition opportunities
5. Validate search intent

### Step 2: Keyword Mapping
1. Map head terms to main pages
2. Map medium-tail to category pages
3. Map long-tail to specific landing pages
4. Map ultra-specific to job detail pages
5. Create keyword cannibalisation rules

### Step 3: Content Creation
1. Create landing pages for valuable keywords
2. Optimize existing pages for target keywords
3. Add FAQ content for question keywords
4. Implement internal linking strategy
5. Monitor performance

### Step 4: Ongoing Optimization
1. Monitor Search Console performance
2. Track keyword rankings
3. Analyze user behavior
4. Iterate based on data
5. Expand successful keyword clusters

## SEO Considerations

### Long-Tail Strategy
- Focus on specific, lower-competition queries
- Create dedicated landing pages
- Use FAQ sections for question-based queries
- Build topical authority through content clusters

### Search Intent Alignment
- Match content to user search intent
- Provide comprehensive answers
- Address different user journey stages
- Optimize for rich results where appropriate

### Content Quality
- Prioritize user value over keyword density
- Create comprehensive, useful content
- Update content regularly
- Remove underperforming content
