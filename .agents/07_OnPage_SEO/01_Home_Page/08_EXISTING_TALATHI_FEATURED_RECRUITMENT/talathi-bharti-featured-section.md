## Responsive UI Direction

Desktop:

```text
Main panel: 2 columns
Left: content, alert and official site link
Right: decorative document visual
Preparation block: 5 subject chips in one row
MSCIT block: icon, text and CTA in one row
```

Tablet:

```text
Main panel: 2 columns if space allows
Preparation block: 2-3 columns
MSCIT block: text-first row
```

Mobile:

```text
Main panel: single column
Visual card appears after content or can be hidden if space is tight
Preparation links stack in 1 column or 2 compact columns
MSCIT block stacks with full-width CTA
```

Mobile rules:

- Keep heading readable on small screens.
- Avoid long Marathi text overflow.
- Use short chips for subjects.
- Keep official site CTA easy to tap.
- Do not place the visual before the main heading.

---

## Scroll Animation Direction

Use subtle reveal animation:

```text
Header badge appears first
Main heading appears second
Alert block appears third
Official site link appears fourth
Document visual appears fifth
Preparation links stagger after main panel
MSCIT block appears last
```

Motion rules:

- Use small upward motion only.
- Use a quiet pulse for the "Coming Soon" dot.
- Do not flash the application alert.
- Run reveal animation once.
- Respect reduced-motion settings.

## Data And Verification Rules

- Do not mark the recruitment as open until the official notification is live.
- Do not show an application link until the official application URL is verified.
- Keep vacancy count blank or "to be announced" until confirmed.
- Keep dates blank or "to be announced" until confirmed.
- Use `mahabhumi.gov.in` as the official reference link.
- If official authority changes, update this section and the Talathi detail page together.
