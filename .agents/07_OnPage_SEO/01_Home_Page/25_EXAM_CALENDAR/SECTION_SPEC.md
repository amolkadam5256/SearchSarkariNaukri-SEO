# Section 25 - Exam Calendar

## Purpose

Help users track upcoming application deadlines, exam dates and result/admit-card events.

## Recommended UI

- Heading: `Government Exam Calendar`
- Description: `Track important recruitment dates, exam schedules, admit card release windows and result updates.`
- Use compact upcoming-events list.

## SEO Keywords

- government exam calendar
- Sarkari exam dates
- recruitment calendar 2026
- upcoming government exams

## Links

- `/exam-calendar`
- `/closing-soon`
- `/admit-cards`
- `/results`

## Rules

Dates must be official or marked tentative with source note.

## Performance And Accessibility

Use `time` elements for dates and cache event queries.
