# Section 48 - How To Apply

## Purpose

Give users a safe application process overview.

## Recommended UI

- Heading: `How To Apply For Government Jobs`
- Steps: Read notification, check eligibility, prepare documents, apply on official website, pay fee if required, save form, track updates.

## SEO Keywords

- how to apply for government jobs
- Sarkari Naukri application process
- government job online form

## Links

- `/how-to-apply`
- `/official-government-job-portals`
- `/documents-required`

## Rules

Do not place third-party application links where official application is required.

## Performance And Accessibility

Use ordered list and clear CTA.
