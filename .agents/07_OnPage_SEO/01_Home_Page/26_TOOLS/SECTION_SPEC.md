Promote useful tools that help users decide eligibility, deadlines and preparation steps.

- Description: `Use practical tools to check eligibility, calculate age, track deadlines and prepare documents.`
- Tool cards: Eligibility Checker, Age Calculator, Deadline Tracker, Document Checklist, Salary/Pay Level Guide.
