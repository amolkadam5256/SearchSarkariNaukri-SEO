# Section 21 - State Jobs

## Purpose

Provide all-India state-wise government job discovery.

## Recommended UI

- Heading: `Government Jobs By State`
- Description: `Find state-wise recruitment updates across India, including Maharashtra, Gujarat, Rajasthan, Karnataka, Tamil Nadu, Uttar Pradesh and West Bengal.`
- Use compact state chips with counts where available.

## SEO Keywords

- state wise government jobs
- Sarkari Naukri by state
- government jobs in India states

## Links

Use live pages like `/jobs-in-maharashtra`, `/jobs-in-gujarat`, `/jobs-in-rajasthan`, `/jobs-in-karnataka`, `/jobs-in-tamil-nadu`, `/jobs-in-uttar-pradesh`.

## Rules

No dead state links. No sitemap inclusion for thin/noindex state pages.

## Performance And Accessibility

Keep state list compact and mobile-scroll friendly.
