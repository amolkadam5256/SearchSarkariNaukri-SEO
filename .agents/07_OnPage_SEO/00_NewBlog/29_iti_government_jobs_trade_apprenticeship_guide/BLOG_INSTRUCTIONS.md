- [ ] H1 is used once and matches the search intent.
- [ ] H2s cover search intent completely: overview, eligibility/process, important documents, official links, mistakes to avoid, FAQs, and next steps.

- [ ] Confirm no thin, duplicate, or generic AI-style paragraphs remain.

## AEO Checklist
- [ ] Add a direct answer paragraph in the first 100 words.
- [ ] Add 5-8 FAQ questions written in natural user language.
- [ ] Answer each FAQ in 40-70 words with a direct first sentence.
- [ ] Include checklist-style answers for process queries.
- [ ] Include definition-style answers where the topic explains a term, department, exam type, document, or process.
- [ ] Use concise tables for eligibility, document list, steps, differences, or timeline where helpful.
- [ ] Avoid vague answers such as "visit the official website" without explaining what to check there.

## GEO Checklist
- [ ] Mention India-wide applicability where relevant.
- [ ] Add Maharashtra context if the topic relates to Maharashtra, district-wise jobs, MPSC, ZP, ITI, diploma, railway, or local recruitment.
- [ ] Include city/district examples only when useful: Pune, Nagpur, Nashik, Mumbai, Thane, Aurangabad/Chhatrapati Sambhajinagar, Kolhapur, Solapur.
- [ ] Do not overuse location terms; keep location mentions tied to actual search intent.
- [ ] If district-wise content is included, make sure district names and department examples are accurate.

## E-E-A-T and Trust Checklist
- [ ] Cite or link official sources for notifications, application portals, results, admit cards, merit lists, or exam bodies.
- [ ] Add a disclaimer that candidates should verify final dates, fees, vacancy counts, and eligibility from the official notification before applying.
- [ ] Use practical, experience-based guidance: document readiness, common rejection reasons, safe browsing, payment confirmation, and print/download proof.
- [ ] Avoid claiming guaranteed selection, confirmed vacancies, or unofficial dates.
- [ ] Make instructions suitable for students, first-time applicants, and parents helping candidates.
