# Publishing and QA Checklist

## Pre-publication

- [ ] Confirm new/update assignment.
- [ ] Verify official links, redirects and canonical destinations.
- [ ] Confirm no duplicate article already satisfies the same intent.
- [ ] Confirm one H1, one primary CTA, visible FAQs and no unsupported factual claims.

## Deployment

- [ ] Publish only after canonical bug checks pass.
- [ ] Confirm route 200, self-canonical before/after hydration, metadata, breadcrumbs and schema.
- [ ] Confirm sitemap inclusion.

## Post-publication

- [ ] Request indexing in Search Console.
- [ ] Check mobile rendering and Core Web Vitals.
- [ ] Monitor impressions/clicks and cannibalization.

Unavailable checks are PENDING until live URL and GSC access exist.
