# Canonical Issue QA and GSC Validation Checklist

## Live Tests

```bash
curl -I "https://www.searchsarkarinaukri.com/jobs/862"
curl -IL "https://www.searchsarkarinaukri.com/jobs/862"
```

If HTTP 200, inspect HTML:

```bash
curl -s "https://www.searchsarkarinaukri.com/jobs/862" | grep -Ei "canonical|robots|JobPosting|BreadcrumbList|<h1"
```

Expected: one clear canonical outcome, no loop, no chain to unrelated page.

## Sitemap Tests

- If `/jobs/862` is canonical and indexable, it may appear in job sitemap.
- If `/jobs/862` redirects to a slug URL, only the slug URL should appear.
- If `/jobs/862` is invalid/expired noindex, it should not appear.

## GSC Validation

1. Inspect `/jobs/862` in Search Console.
2. Run live test.
3. Confirm Google sees the same canonical/redirect as users.
4. Inspect canonical target.
5. Request indexing only for the canonical job page if it should be indexed.
6. Validate the issue after deployment.

## Developer Scope Guardrail

Do not change unrelated pages, footer, navbar, header, menu, site-wide layout, global styling, tracking setup, analytics setup, or shared components unless strictly required for this canonical fix.
