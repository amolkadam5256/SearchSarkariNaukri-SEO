# SearchSarkariNaukri — Complete District URL, Redirect, Indexing & Location SEO Fix Specification

## 1. PRIMARY ISSUE

Google Search Console currently reports:

**URL:**
`https://www.searchsarkarinaukri.com/jobs?district_slug=pune`

**Status:**
`URL is not on Google`

**Page indexing reason:**
`Redirect error`

**Google crawl:**

* Googlebot smartphone
* Crawl allowed: Yes
* Last crawl: 7 June 2026
* Page fetch: Failed — Redirect error
* Indexing: N/A
* Canonical: N/A

The expected URL architecture is:

`/jobs?district_slug=pune`
→ `301`
→ `/districts/pune`

The destination page should be the canonical, indexable district landing page.

IMPORTANT:

Do not try to make the query-parameter URL indexable.

The clean URL:

`https://www.searchsarkarinaukri.com/districts/pune`

must be the permanent SEO URL.

---

# 2. FIRST PRIORITY — FIX REDIRECT LOGIC

Audit the complete redirect implementation.

Find every place where the application handles:

* `/jobs`
* `district_slug`
* query parameters
* district filters
* middleware redirects
* Next.js redirects
* route handlers
* server components
* client-side navigation
* canonical generation
* trailing slash handling
* locale handling
* authentication redirects
* expired/invalid district redirects

Do NOT have multiple redirect layers.

Bad:

`/jobs?district_slug=pune`
→ `/jobs?district=pune`
→ `/districts/pune`
→ `/districts/pune/`

Good:

`/jobs?district_slug=pune`
→ `301`
→ `/districts/pune`

Only one canonical redirect.

---

# 3. REDIRECT MUST BE SERVER-SIDE

The redirect must happen before the page renders.

Do NOT implement this as:

* JavaScript redirect
* `window.location`
* client `useEffect`
* loading-page redirect
* meta refresh
* client router redirect after rendering

Use the framework/server routing layer.

For Next.js, inspect:

* `next.config.*`
* `middleware.*`
* App Router route files
* route handlers
* server components
* existing redirect utilities

The redirect must return a permanent HTTP redirect.

Expected behavior:

```text
GET /jobs?district_slug=pune
HTTP 301/308
Location: /districts/pune
```

Use one permanent redirect strategy consistently.

Do not create a redirect loop.
