## ✅ Global Off-Page SEO Rules (Apply Everywhere)

1. Always include **canonical URL** pointing to `searchsarkarinaukri.com` where applicable.
2. Add **10–20 contextual internal links** from SSN sitemaps per post.
3. Every post must link back to the **main SSN website**.
4. Include **social media profile links** in every post footer/bio.
5. Use the **approved image format: 16:9**, high-quality, topic-relevant creative.
6. All posts must follow the **SEO format**: title → subtitle → content → topics → FAQs → CTA.
7. Log every post in the respective **platform log file**.
