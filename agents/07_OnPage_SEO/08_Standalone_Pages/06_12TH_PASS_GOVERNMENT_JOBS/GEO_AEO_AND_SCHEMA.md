# GEO, AEO and Structured Data

## GEO and answer readiness

- [ ] State plainly which jobs accept Class 12 candidates and which additional post-specific requirements apply.
- [ ] Keep critical details in crawlable HTML.
- [ ] Cite the responsible authority and notice date for time-sensitive facts.
- [ ] Distinguish official notices from editorial guidance and state-specific from central recruitment.
- [ ] Use direct answers and descriptive question headings where useful.
- [ ] Avoid hidden text, repetitive keywords or claims that optimization guarantees citations/rankings.

## Structured data

- [ ] Audit existing JSON-LD and shared-layout schema before editing.
- [ ] Use only schema types appropriate to visible page content and current eligibility rules.
- [ ] Use `BreadcrumbList` only when it matches visible breadcrumbs.
- [ ] Do not use `JobPosting` for this general qualification listing page. Individual vacancy pages may be evaluated separately against current requirements.
- [ ] Do not invent vacancies, dates, salary, employer, location or status to populate schema.
- [ ] Ensure schema matches visible data and canonical URL; avoid duplicate objects.
- [ ] Validate representative output and record the actual result.
