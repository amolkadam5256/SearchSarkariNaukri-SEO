# Developer Instructions — 12th Pass Government Jobs

## Before implementation

1. Read the repository agent rules and the no-delete policy if present.
2. Inspect the route component, qualification-page pattern, job model/data source, metadata generator, filters, pagination, schema, analytics and current page behavior.
3. Capture the current page and exact URL robots/indexability baseline.
4. Review the separate informational article and preserve its distinct intent.
5. Verify current records against official notices, especially the reported active count and deadlines of 27 October 2026.

## Build

1. Enhance the existing route; do not create a duplicate.
2. Keep current vacancy discovery central and add at least 15 useful sections and 15 FAQs.
3. Use real job records and the data-status rules. Expired listings must not retain active application actions.
4. Connect relevant internal pages and official external notices; validate every destination.
5. Implement responsive, accessible filters/cards and all relevant loading, error, empty, active and closed states.
6. Verify title, description, H1, canonical, robots, HTTP headers, sitemap, rendered content, schema, analytics and consent behavior.
7. Do not remove or overwrite existing page content, routes, data, metadata, tracking or functionality.

## Pass 1 — Implementation review

- [ ] Every required content section and at least 15 FAQs is present and useful.
- [ ] Every visible vacancy and active count is supported by current records and official sources.
- [ ] Expired, extended, cancelled and result-stage listings use accurate status/actions.
- [ ] Internal/external destinations work and have accurate labels.
- [ ] Metadata, exact URL indexability, schema and sitemap policy are checked.
- [ ] Filters, pagination, URL state, empty/loading/error states work.
- [ ] Applicable lint, type, test and build scripts run; results are recorded.
- [ ] Existing content and behavior are preserved; changed files and data issues are recorded.

## Pass 2 — Independent review

- [ ] Recheck all sections, FAQ answers and source-linked facts against the rendered page.
- [ ] Recalculate active counts and deadlines; verify no expired Apply action remains.
- [ ] Reinspect rendered robots meta, response `X-Robots-Tag`, canonical, HTTP status and sitemap for this exact URL.
- [ ] Check Search Console URL Inspection/live test if authorized; do not infer its result.
- [ ] Retest links, filters, sorting, pagination, URL state and all relevant record states.
- [ ] Test mobile/tablet/desktop, keyboard and assistive-technology behavior.
- [ ] Inspect console/network errors and unrelated-route regressions.
- [ ] Record evidence and leave unresolved items open.

## Handoff

Report files changed, sections/FAQ count, vacancy records corrected, links checked, exact-URL indexability result, tests/build, unresolved issues and confirmation of content/function preservation. Do not claim a #1 ranking or report verification that was not performed.
