# UI/UX, Responsive Design and Accessibility

- [ ] Reuse the existing design system and shared components.
- [ ] Put the introduction, current status and quick navigation near the top.
- [ ] Show concise totals for active/upcoming/closed records only when supported by current data.
- [ ] Add filters for qualification, state, department, organization, job type and status only where the data supports them.
- [ ] Ensure filtering works with pagination and URL state.
- [ ] Provide clear loading, error, empty and no-results states.
- [ ] Make job cards scannable: title, authority, qualification, location, verified deadline, status and official action.
- [ ] Use installed icons consistently; do not add dependencies without need.
- [ ] Ensure official source/application links are visually clear.
- [ ] Make FAQ controls keyboard-operable and accessible to assistive technology.
- [ ] Keep page usable on mobile, tablet and desktop; prevent clipping and horizontal overflow.
- [ ] Use readable type, adequate contrast, visible focus and semantic controls.
- [ ] Do not hide essential eligibility or status information inside interactions.
- [ ] Preserve the global header/footer, analytics and consent behavior.
