# New Blog Workflow

Use [BLOG_CREATION_MASTER_RULES.md](BLOG_CREATION_MASTER_RULES.md) whenever a new blog is requested or source material is provided for a blog. It is the editorial brief for researching, drafting, and packaging each article.

## For every new blog request

1. Read the master rules and any topic-specific instructions in the relevant blog folder.
2. Inventory the existing blog files, cluster map, relevant website pages, and current published URLs before choosing the keyword, angle, or slug. Do not assume old audit snapshots or calendars are current.
3. Verify time-sensitive claims with primary/official sources and disclose gaps. Do not invent keyword volumes, vacancies, dates, pay, eligibility, source checks, or rankings.
4. Deliver the article with its SEO brief, sources, internal link plan, and topic-specific visual direction. Apply the publishing checklist only if the request includes implementation or publication.
