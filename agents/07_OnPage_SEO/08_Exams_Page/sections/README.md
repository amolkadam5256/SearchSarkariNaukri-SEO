## Required two-pass verification

Every section instruction sheet contains its own Pass 1 implementation review, Pass 2 independent verification, and completion record. Complete both passes for every section. Pass 1 checks the implementation against the requirements and source data. Pass 2 independently checks the rendered page and interactions on desktop and mobile. Record evidence and defects; do not mark unverified items complete.

**Scope rule:** Keep all existing page sections and useful content. The directory must retain all 40 exams. A checklist is complete only when the implementation has been inspected and the applicable behavior has been exercised.
