## 7. Developer Rules for Link Graph Integrity

1. **Clean Crawlable `<a>` Tags:** Always render links as `<a href="...">...</a>`. Never use JavaScript `onClick="window.location=..."` or synthetic `<div>` links.
2. **No Orphan Pages:** Every linked page must return HTTP status 200 and feature breadcrumb links pointing back to `/category/state-government-jobs` and `/`.
3. **No Redirect Chains:** Ensure URLs use the canonical trailing slash / non-trailing slash pattern consistently.
4. **Anchor Text Diversity:** Avoid repeating exact-match keywords identically. Blend natural descriptive variants (e.g., *Check your eligibility*, *Government Job Eligibility Checker*, *Evaluate state job eligibility*).
5. **No `nofollow` on Internal Links:** All internal links within the SearchSarkariNaukri network must pass full link equity (`rel="follow"` by default).
