# 15 — Local SEO & Regional Language Optimization

## 15.1 Regional Vernacular Strategy

To capture regional search volume in non-English queries across India:
- **Secondary Language Focus:** Marathi and Hindi regional landing pages (`/hi/jobs/...`, `/mr/jobs/...`).
- **Hreflang Tags:** Deploy explicit hreflang tags when regional versions exist:
```html
<link rel="alternate" hreflang="en-in" href="https://www.searchsarkarinaukri.com/jobs/ssc-cgl-2026" />
<link rel="alternate" hreflang="hi-in" href="https://www.searchsarkarinaukri.com/hi/jobs/ssc-cgl-2026" />
<link rel="alternate" hreflang="mr-in" href="https://www.searchsarkarinaukri.com/mr/jobs/ssc-cgl-2026" />
<link rel="alternate" hreflang="x-default" href="https://www.searchsarkarinaukri.com/jobs/ssc-cgl-2026" />
```

## 15.2 District Landing Page Scale Architecture

- **700+ District Pages:** `/district/[district-slug]` landing pages catering to candidates searching for local district court, municipality, district police, and collectorate vacancies.
- **Dynamic Filtering:** District pages pull active state jobs filtered specifically by candidate location.
