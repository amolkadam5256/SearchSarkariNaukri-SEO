## 16.2 Anchor Text Distribution Strategy

Maintain a natural, safe anchor text profile:
- **Branded Anchors (35–40%):** *SearchSarkariNaukri*, *SearchSarkariNaukri.com*, *Search Sarkari Naukri portal*
- **Naked URLs (20–25%):** *https://www.searchsarkarinaukri.com*, *searchsarkarinaukri.com*
- **Generic Anchors (15–20%):** *visit website*, *check notification*, *official page*, *learn more*
- **Partial-Match Keywords (10–15%):** *latest sarkari naukri updates*, *UP police recruitment details*
- **Exact-Match Keywords (5–10%):** *sarkari naukri 2026*, *railway bharti 2026*

## 16.3 Toxic Backlink Audit & Disavow SOP

### 7-Step Disavow Process
1. **Monthly Export:** Export complete backlink profile from Ahrefs and SEMrush on the 1st of every month.
2. **Spam Filtering:** Filter for toxic link indicators (DR < 5, adult/gambling keywords, PBN link networks, foreign spam TLDs like `.xyz`, `.top`, `.ru`).
3. **Manual Inspection:** Manually inspect flagged domain samples to verify non-relevance.
4. **Outreach for Removal:** Send up to 2 removal requests to domain webmasters (document outreach attempts).
5. **Disavow File Compilation:** Format disavow directives in standard text format:
```
# Disavow file for searchsarkarinaukri.com - Updated 2026-07-23
domain:spam-job-aggregator.xyz
domain:pbn-link-farm.top
https://bad-site.com/spam-page.html
```
6. **Submission:** Upload updated disavow text file directly to [Google Search Console Disavow Tool](https://search.google.com/search-console/disavow-links).
7. **Documentation:** Log all disavowed domains in master security register.
