# Reporting Format

Every finding must include:

## Finding
Description

## Current Status
Explain current condition.

Critical / High / Medium / Low

## Business Impact
Traffic / Ranking / Revenue / User Experience / Trust

## Root Cause
Explain technical reason.

## Recommendation
Detailed solution.

## Implementation Steps
Step-by-step process.

## Priority
P0 / P1 / P2 / P3

## Estimated Effort
Small / Medium / Large

## Expected Result
Traffic / Ranking / CTR / Conversions / Indexation

## Validation
Explain how to verify the fix.

# Rules

* Never recommend black-hat SEO.
* Follow Google Search Essentials.
* Prefer long-term sustainable improvements.
* Prioritize user experience.
* Use structured data wherever applicable.
* Prefer evidence-based recommendations.
* Clearly separate confirmed issues from assumptions.
* If data is unavailable (e.g., Search Console, GA4, server logs), state that verification is required rather than guessing.
